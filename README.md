# M-Anchor App

AIが作った記録の更新案を検査し、定めた条件を満たす更新だけを正本に保存するローカルアプリです。

**Model proposes; deterministic layer commits.**

モデルは更新案を作り、モデルとは別の規則に基づくGateとストアが保存の可否を決めます。根拠のない確定によって未決の候補が失われることを防ぎ、認可された証拠による更新は通します。

## 現在の状況

2026年9月30日現在、ローカル試作版 v0.2（画面名：Anchor Control）の基本動作を確認しています。

- Windows上のローカルサーバーとブラウザ画面
- 専用PythonクライアントとOpenAI Responses APIの接続
- SQLiteへの案件記録の保存と更新履歴
- 根拠のない候補削除の拒否、未決状態の保持、認可済み証拠による更新

確認範囲は人工的な二案件を使った基本動作です。実モデルによる未決保持と、Gateによる不正案の拒否は区別して記録しています。

## 対象範囲

保護対象はアプリのストア内の案件記録です。証拠の認可と解釈はモデルの外で設定します。外部ツールの実行制御や、証拠内容の真偽判定は初版の対象に含めません。
