What this demo showsこのデモで確認すること

The record starts with hypotheses A (h_A) and B (h_B). The synthetic evidence e_B is configured in advance to support B alone.仮説A（h_A）と仮説B（h_B）が残っている記録を使います。証拠e_Bは、あらかじめ「Bだけが残る」と設定した人工的な証拠です。

DEMO-HOLD · Preserve uncertaintyDEMO-HOLD · 未決を守る

Without admitted evidence証拠がないとき

Even when AI is asked to settle on B, the authoritative record keeps both A and B.AIに「Bに確定して」と求めても、正本にはAとBの両方を残します。

DEMO-UPDATE · Allow a supported updateDEMO-UPDATE · 正当な更新を通す

With admitted evidence認可された証拠があるとき

Update the authoritative record to B using e_B, which is admitted for this case.この案件に認可されたe_Bに従い、正本の候補をBに更新します。

A proposal that preserves uncertainty yields “No change”. An unsupported candidate removal is “Rejected”. Both preserve the unresolved record.モデルが未決を保つ場合は「変更なし」、根拠なく候補を削る案は「拒否」です。いずれも正本の未決を保持します。

How to read these recordsこの記録から分かること
Proposals received since v0.4 include receipt time, submission route, and available model metadata. Missing older metadata is shown as “Not recorded”. Routes describe server processing; they do not prove that a client API caller is AI. Key input values are excluded from exports. V1 model runs also include the exact input text and its hash. Scenario names describe the selected exercise, not detected attacks. Input text, proposals, and case contents are included, so review them before sharing.v0.4以降で受け付けた提案には、受信日時・提出経路・モデル利用情報を保存します。旧版で記録しなかった情報は「未記録」と表示します。提出経路はアプリの処理経路を示します。クライアントAPIの呼出元がAIかどうかは識別しません。キー入力欄の値は出力しません。V1のモデル実行では入力原文とハッシュも残します。シナリオ名は選択した演習であり、攻撃検出の結果ではありません。入力・提案・案件内容を含むため、共有前に確認してください。
